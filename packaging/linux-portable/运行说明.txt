BIT比特充电—单机便携演示包

一、如何运行
1. 保留本文件夹的完整结构，不要只拷贝 bin 中的程序。
2. 双击“运行演示.sh”，若文件管理器询问，选择“运”或“作为程序运行”。
3. 管理端和用户端会同时启动。关闭用户端后，本次启动的服务器也会退出。

二、数据与重复演示
数据保存在 runtime/evplatform.db，再次启动会继续使用。
要恢复初始模拟数据，先关闭两个程序，再备份或删除 runtime 中的 evplatform.db、evplatform.db-wal 和 evplatform.db-shm。
下次运行时服务器会自动重建演示数据。

三、包内容和系统边界
本包已携带两个 Release 程序、Qt 动态库和插件、SQLite 插件、QtWebEngineProcess、Chromium 资源、语言文件以及已配置的腾讯位置服务 Key。
目标环境是 glibc 2.34 或更高版本的 x86_64 Linux 图形桌面（例如 Ubuntu 22.04/24.04）；本包在 Ubuntu 24.04 完成验证。操作系统仍需提供 Linux 内核、glibc、X11/XCB 基础库、显卡驱动/Mesa、字体和声音等桌面基础组件；它们不属于应用私有运行库。
演示腾讯地图需要可用的互联网连接。

如需排查包是否完整，双击“检查完整性.sh”或在本目录运行它。
